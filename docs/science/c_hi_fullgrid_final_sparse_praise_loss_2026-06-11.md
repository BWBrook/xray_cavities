# C-HI Full-grid Final Sparse PRAiSE-compatible Loss Table

Date: 2026-06-11

## Summary

This note records the first bounded PRAiSE-compatible external loss table for
the completed 50 Myr `C-HI` full-grid sparse selected-particle window, and the
first Goal 001 sparse radio bridge run using that table through `--loss-table`.

The purpose was to replace the June pressure-history attenuation proxy with a
selected-ID keyed loss table generated by the staged XRAiSE/PRAiSE particle
runtime, without building a dense all-history particle HDF5 cache.

This is an interface and provenance product. It is not a final publication
radio product: the history is the final sparse window, the luminosity scale
still uses the existing `1.0 kpc^3` per selected particle convention, the map
is not beam-convolved, and the final observable-comparison page is still out of
scope.

## Method

The helper constructs the minimal particle-history arrays consumed by the
staged `xraise.praise(...)` call:

- selected IDs and window indices come from the final sparse-window metadata;
- particle fields are read only for the selected IDs and the bounded sparse
  window outputs `4950, 4955, ..., 5000`;
- fields passed to PRAiSE are `density`, `pressure`, `tracer`, and
  `last_shock_time`;
- the PRAiSE call uses the existing project defaults: `150 MHz`, `redshift =
  0.05`, `eta = 0.03`, `s = 2.2`, `gmin = 500`, `gmax = 1e5`, `losses = 4`,
  `window_width = 5`, and `smooth_order = 3`;
- output is keyed as `id,loss_factor`, then consumed by
  `scripts/science/sparse_particle_radio_bridge.py --loss-table`.

The full bridge metadata reports:

```text
loss_model_key = external_praise_compatible
matched_selected_ids = 20000
extra_ids = 0
table_rows = 20000
```

## Caveats

- The table uses the final sparse time window, not a dense all-history
  particle cache.
- The bridge still uses `1.0 kpc^3` per selected particle rather than final
  grid/tracer volume coupling.
- The maps are particle-binned and not beam-convolved.
- No final observable-comparison page was built in this goal.
- Scientific defaults were not changed.

## Interpretation

Goal 002 closes the external-table interface gate for the final sparse
selected IDs. The bridge can now consume a real selected-ID PRAiSE-compatible
loss table and produce a compact radio map, lobe summary, metadata, and local
review assets.

The next review should inspect the new helper, tests, and remote provenance,
then decide the next science goal: likely a final review/refinement pass that
ties this product to grid/tracer volume coupling and the observable comparison
page without changing the established sparse selected-ID contract.
