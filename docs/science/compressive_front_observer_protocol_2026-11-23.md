# Comparing the G-HI compression front with the exposed X-ray arcs

G-HI is the group atmosphere `002031`, with bipolar labelled power $2\times10^{45}$ erg s⁻¹, a $0.1c$ jet, a 15° half-opening angle and a 0.75-kpc injection height. The stretched Cartesian grid has 960 × 960 × 1,014 cells over ±200 kpc in x and y and ±250 kpc in z. The HLLC run used CFL 0.33 and an initial step of $10^{-5}$ in code units. Single-precision native fields were scheduled every 306.60139379 code units (about one Myr). Snapshot 20 is at **19.999614294878622 Myr**. Each 1-keV sightline is perpendicular to the jet; the three azimuths are 0°, 45° and 90°. This protocol concerns only the previously exposed development snapshot. ## Geometry and profiles

Register the reference images, original fitted backgrounds, stored orange 5%-deficit and blue seed/grow masks, positive tracer path, and new native projections by exact pixel edges. The raw map is the original image used to select the two outlines. For the deficit map use its original radial background. Emission changes use the exact-edge brightness reconstruction. Show the 120-kpc aperture and all projected lobe edges, including holes. Distinguish the projected path of the independently defined compressive cells from their emissivity. The projected footprint is the union of sightlines with positive front path. Its boundary can include holes and separate components.

For each observer outline, locate every exposed rectangular pixel face exactly. Sample at the midpoint of each face and measure the shortest physical distance to the segments of the reference contour. A negative distance is inside the projected reference footprint, a positive distance is outside, zero is on its boundary. Weight the distribution by physical face length. Report hemispheres separately and keep subpixel distances in kpc. Normalise front distances also by the local native physical cell scale at the nearest front pixel; record the sky-pixel scale separately. Give the share within one native scale and the share farther inside/outside. For near coincidences, the nearest front boundary either faces the connected exterior or bounds an interior hole. Alignment with the edge of a projected footprint cannot identify a physical shell tangent or prove a causal effect. Always carry the loose/strict native choices and report missing footprints as unavailable.

The lateral-arc subset comprises orange pixels beyond the outermost full-tracer pixel on the same side of the jet axis at the same z, in rows with a tracer lobe on that side. Report all orange and blue contour faces as well as this subset; the test is not restricted to a favourable azimuth. For each hemisphere choose two transverse profiles before comparing with the native front. The arc profile crosses the row with the largest **total physical width** of lateral orange excess. The lobe profile crosses the row with the largest area-integrated tracer path per unit axial width. Lowest array index resolves a tie. A hemisphere without a lateral arc has no arc profile. Curves and profile coordinates identify the selection explicitly.

## Emission and controlled replacement

For the primary retained-linear prescription, compare the full-sightline contributions from tracer-selected cells, current front-associated ambient cells and the complementary atmosphere, both now and at time zero in the same current cells. Sum the independently accumulated components against the old exact-edge total for every pixel and retain signed residuals. Integrate by exact projected area, separately for each side, on blue-missed and orange-missed full-lobe sightlines, the exterior orange lateral arcs and the one-pixel inner rim of those arcs. Include total area, signed component changes and both epoch sums. The sign convention for emission change is current minus initial.

Replace only the current front-associated ambient emission by its same-cell initial value. Compare original-image selection, the exact-edge baseline and the replacement, both with the original observer backgrounds held fixed and with each background refitted. Report areas, completeness, purity and symmetrised revolution volumes on each side. The original 1-keV maps and two outline methods remain fixed. The front measurement has no role in the frozen 54-view detector predictions.
