# Plan: Goal 046

## Phase 0 - Freeze The Scientific Contract

- Record repository orientation and preserve the inherited worktree.
- Supersede the unexecuted Goal 042 proposal without treating its old ledger
  or Goal 043 naming as current authority.
- Build exact remote-root and protected-path contracts from accepted C-HI,
  C-LO, and G-LO evidence.
- Bind both contracts to a deterministic digest.

Stop if a protected source, restart tuple, radio hold, or root owner is
ambiguous.

## Phase 1 - Inventory Read-Only

- Preflight every protected path and required HDF5 identity.
- Submit one allowlist-only PBS inventory job when login-node hashing is not
  appropriate.
- Record regular files, symlinks, path identity, apparent and allocated bytes,
  full candidate hashes, HDF5 metadata, and catalogue membership.
- Detect tree changes during traversal and fail closed.
- Retrieve only compact inventory, catalogue, scheduler, and provenance
  evidence.

No deletion, move, truncation, overwrite, or permission change is permitted.

## Phase 2 - Build The Exact Ledger

- Assign exactly one lifecycle action to all inventoried payload rows.
- Protect the accepted dependency union.
- Hold all particle payloads while radio retention remains unresolved.
- Hold symlinks and any identity, ownership, or lineage ambiguity.
- Propose only full-hashed, stable, regular files for deletion.
- Require complete HDF5/XMF pairing and catalogue membership for production
  candidates.
- State rollback or regeneration consequences for every proposed action.

Analysis products without per-row regeneration lineage remain held. Their
small possible recovery does not justify weakening the approval surface.

## Phase 3 - Independent Reconciliation

- Recompute row counts, byte totals, full-hash coverage, path normalization,
  pair completeness, catalogue membership, and protected/held anti-joins.
- Bind the ledger to a SHA-256 digest.
- Test coherent tampering, path traversal, protected-row substitution,
  manifest omission, stale job evidence, and digest mismatch.
- Audit the irreversible scientific tradeoff independently.
- Perform one focused repair for material findings, then stop.

## Phase 4 - Package And Request Approval

- Write the dated science note and exact machine-readable packet.
- Record repaired PBS completion and archive provenance honestly.
- Preserve the original archive and any known metadata-only packaging defect.
- Update the exchange log, current status, and Goal log.
- Report the exact proposed deletion rows, recoverable bytes, holds, and ledger
  digest.

Goal 046 stops at `approval_packet_ready`. It has no deletion capability.

## Phase 5 - Future Goal 047 Boundary

Goal 047 may start only after Barry explicitly approves the exact Goal 046
ledger digest. It must:

- refresh PBS job state immediately before action;
- revalidate every approved row against path identity and full SHA-256;
- operate only on exact, nonrecursive, normalized ledger paths;
- stop on the first mismatch;
- preserve an append-only transcript; and
- complete the post-deletion validation specified in the Goal 046 Runbook.

Any changed digest, expanded scope, or new scientific dependency requires a
new approval.
